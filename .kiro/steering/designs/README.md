# Ambrosia — Reference Screen Images

Save the uploaded design screenshots into **this folder** (`.kiro/steering/designs/`) using
the exact filenames below. The brand guide and the screen index reference these paths, so once
the files are here they are automatically wired into Kiro's context.

> Chat attachments can't be written to disk automatically — you must save each image here manually
> (drag the file into this folder in the explorer, or export from your design tool).

## Expected filenames

| Filename | Screen |
|---|---|
| `logo-red.png` | Red logo + wordmark + tagline |
| `logo-white.png` | White line-art logo |
| `onboarding-1-breast-health.png` | Onboarding slide 1 ("Your health is a collective effort...") |
| `onboarding-2-parenting.png` | Onboarding slide 2 ("Parenting and childcare...") |
| `onboarding-3-health-priority.png` | Onboarding slide 3 ("Taking care of your health...") |
| `auth-signin.png` | Sign in |
| `auth-account-type.png` | Choose an account type |
| `register-step-1-details.png` | Step 1 — Your Details |
| `register-step-1-errors.png` | Step 1 — error state |
| `register-step-2-account-info.png` | Step 2 — Account Info |
| `register-step-3-currency.png` | Step 3 — Primary Currency |
| `register-step-4-pin.png` | Step 4 — Transaction Pin |
| `register-step-5-interests.png` | Step 5 — Health Interest |
| `home-foryou-feed.png` | Home "FOR YOU" feed |

File format: PNG preferred (JPG/WEBP also fine). Keep each under 10MB.
